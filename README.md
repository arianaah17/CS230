The user needed a web-based program that was still relatively translatable to their mobile setup. The clients also wanted the ability to log in and receive informaation for the players and admin. These indicatrs allow for the program to be written up while following the expectations of the clients so that everyone involved has a clear understanding of what the system is expected to look like and function.
